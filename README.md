# DAMI KOREAN - 김다미 한국어 선생님 공식 웹사이트

> **"가장 쉬운 한국어, 가장 가까운 한국어"**  
> 어려운 한국어는 쉽게, 배운 한국어는 실제로 사용할 수 있게.

김다미 한국어 선생님의 교육 철학과 전문성, 한국어 학습 콘텐츠(문법, 발음, 덩어리 표현, 실전 담화, 어휘 등), AI 활용 비전을 담은 웹사이트입니다.

---

## 🌟 주요 기능 및 특징

1. **순수 웹 기술 기반 (No Backend/Python)**
   - HTML5, CSS3, Vanilla JavaScript로만 제작되어 별도의 서버나 런타임 설치 없이 브라우저에서 바로 동작합니다.
   - GitHub Pages에 올리면 즉시 무료로 웹 호스팅이 가능합니다.

2. **반응형 웹 디자인 (Responsive Design)**
   - PC, 태블릿, 모바일 기기 모두에 최적화된 유려한 레이아웃과 모바일 햄버거 메뉴를 지원합니다.

3. **오늘의 한국어 (Today's Korean)**
   - 자바스크립트로 구현된 랜덤 표현 추천 기능
   - Web Speech API를 활용한 원어민 억양의 한국어 발음 듣기(TTS) 지원

4. **12개 핵심 학습 카테고리 (Learn Korean)**
   - 문법, 발음, 덩어리 표현, 담화, 어휘, 관용표현, 속담, 듣기, 말하기, 읽기, 쓰기, 한국문화
   - 카드 클릭 시 상세한 학습 안내와 예문을 보여주는 인터랙티브 모달 팝업

5. **실전 덩어리 표현 (Korean Chunks) & 담화 (Discourse)**
   - 한국인이 매일 쓰는 대표 청크 9종 및 발음 듣기
   - 교재 문장 vs 실제 한국인의 완곡한 배려 표현 비교

6. **AI × Korean Education & Books**
   - AI를 활용한 맞춤형 한국어 교육 10대 연구 분야
   - 출간 예정인 7종 교재 라인업 (Coming Soon)

## 📂 프로젝트 구조

```text
├── index.html                  # 메인 웹페이지
├── dami_korean_single.html     # 스타일/스크립트 내장 올인원 단일 HTML 파일
├── css/
│   └── styles.css              # Warm Cream 테마 및 반응형 스타일시트
├── js/
│   ├── data.js                 # 학습 콘텐츠 및 브랜드 데이터 모듈
│   └── main.js                 # 인터랙션, 모달, TTS, 폼 이벤트 제어
└── assets/
    └── teacher_dami.jpg        # 프로필 이미지
```
